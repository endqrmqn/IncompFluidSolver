# Immersed Boundary Flow Solver (IBFS)

Two-dimensional incompressible flow solver with an immersed boundary.

## Documentation
- From the root directory, execute the command `open docs/build/html/index.html`

## Dependencies
- Python modules `numpy`, `scipy`, `sys`, `os`, `matplotlib`

## Installation instructions
- Navigate to the package's root directory
- Exectute the command `pip install -e .`

## Run tests
- Navigate to the `tests/` directory
- Execute the command `python3 -u test_name.py`
